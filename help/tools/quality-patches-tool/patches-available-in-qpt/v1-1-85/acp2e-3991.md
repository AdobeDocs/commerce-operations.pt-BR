# ACP2E-3991: O endereço IP do cliente não foi determinado corretamente

O patch ACP2E-3991 corrige o problema em que o endereço IP do cliente não é determinado corretamente e é salvo como `127.0.0.1` no campo `remote_ip` da tabela `sales_order`. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.85 está instalado. A ID do patch é ACP2E-3991. Observe que esse problema foi corrigido no Adobe Commerce 2.4.9.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.7-p6, 2.4.8-p5

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.7 - 2.4.8-p5

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

Problema em que o endereço IP do cliente não é determinado corretamente e é salvo como `127.0.0.1` no campo `remote_ip` da tabela `sales_order`.

<u>Etapas a serem reproduzidas</u>:

1. Configure o Servidor de Aplicativos GraphQL em uma instância do Commerce Cloud.
1. Faça um pedido por meio do GraphQL.
1. Verifique o campo `remote_ip` na tabela `sales_order` para a ordem que você criou.
1. Verifique o log de acesso.

<u>Resultados esperados</u>:

O endereço IP correto é registrado, mesmo quando a solicitação é roteada pelo GraphQL.

<u>Resultados reais</u>:

O campo `remote_ip` é salvo como `127.0.0.1` em vez do endereço IP real do cliente.
