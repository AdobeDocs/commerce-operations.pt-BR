# ACP2E-5183: Falha na implantação de conteúdo estático no PHP 8.5 com `@magento_import`

O patch ACP2E-5183 corrige o problema em que a implantação de conteúdo estático falha no PHP 8.5 com o erro *Usar null como um deslocamento de matriz é descontinuado* quando um arquivo de módulo `LESS` usa a diretiva `@magento_import`. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 está instalado. A ID do patch é ACP2E-5183. Observe que esse problema está programado para ser corrigido no Adobe Commerce 2.4.10.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.9

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.4 - 2.4.9

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=pt-BR). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

A implantação de conteúdo estático falha no PHP 8.5 com o erro *Usar nulo como um deslocamento de matriz é descontinuado* quando um arquivo de módulo `LESS` usa a diretiva `@magento_import`.

<u>Pré-requisitos</u>:

O PHP 8.5 está instalado.

<u>Etapas a serem reproduzidas</u>:

1. Habilite um módulo personalizado que forneça um arquivo `email-inline.less` contendo um estilo de corpo de email personalizado e uma diretiva `@magento_import`.
1. Remover conteúdo estático e arquivos gerados:

   ```
   rm -rf pub/static/frontend/* var/view_preprocessed/* generated/code/*
   ```

1. Execute a implantação de conteúdo estático usando a estratégia compacta:

   ```
   bin/magento setup:static-content:deploy --ansi --no-interaction -f -s compact --jobs 4 --no-html-minify
   ```

<u>Resultados esperados</u>:

A implantação de conteúdo estático é concluída com êxito e gera o CSS compilado para o arquivo `LESS` fornecido pelo módulo.

<u>Resultados reais</u>:

A implantação de conteúdo estático é anulada ao compilar o arquivo `email-inline.less` fornecido pelo módulo e os relatórios:

```
Deprecated Functionality: Using null as an array offset is deprecated, use an empty string instead in <magento_root>/vendor/magento/framework/Component/ComponentRegistrar.php on line 71
```
