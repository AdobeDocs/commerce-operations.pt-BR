# ACP2E-5242: O GraphQL usa a ID da loja como a ID do site durante solicitações de adição ao carrinho

O patch ACP2E-5242 corrige o problema em que a verificação da disponibilidade do produto ao adicionar itens ao carrinho exibe um erro indicando que o site não pode ser encontrado. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 está instalado. A ID do patch é ACP2E-5242. Observe que esse problema está programado para ser corrigido no Adobe Commerce 2.4.10.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.9

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.9

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=pt-BR). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

Verificar a disponibilidade do produto ao adicionar itens ao carrinho exibe um erro que indica que o site não pode ser encontrado.

<u>Etapas a serem reproduzidas</u>:

1. Faça logon no Painel de administração.
1. Vá para **Admin** > **[!UICONTROL Stores]** > **Configurações** > **[!UICONTROL All Stores]**, clique em **[!UICONTROL Create Store View]**.
1. Crie uma segunda visualização de loja chamada &quot;store_2&quot;, por exemplo.
1. Crie um carrinho de convidado vazio com uma solicitação do GraphQL usando o cabeçalho HTTP &quot;Store: store2&quot;.
1. Registre a ID do carrinho retornada.
1. Adicione um produto simples ao carrinho com uma solicitação do GraphQL usando o cabeçalho HTTP &quot;Store: store2&quot;, o SKU do produto e a ID do carrinho.

<u>Resultados esperados</u>:

O produto foi adicionado com sucesso ao carrinho por meio da solicitação do GraphQL.

<u>Resultados reais</u>:

A solicitação do GraphQL falha e escreve a mensagem &quot;O site com a ID ... solicitado não foi encontrado. Verifique o site e tente novamente.&quot; para var/log/exception.log.
