# AC-15494: a consulta de produtos do GraphQL retorna nomes de produtos com escape do HTML

O patch AC-15494 corrige o problema em que a consulta do `products` retorna nomes de produtos com caracteres especiais com escape HTML em vez de seus caracteres originais. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 está instalado. A ID do patch é AC-15494. Observe que esse problema está programado para ser corrigido no Adobe Commerce 2.4.9.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.8-p5

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=pt-BR). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

A consulta `products` retorna nomes de produtos com caracteres especiais com escape de HTML em vez de seus caracteres originais.

<u>Etapas a serem reproduzidas</u>:

1. Crie um novo produto chamado `55" 4K UHD Smart TV` com SKU `testsku`.
1. Envie a seguinte consulta do GraphQL:

   ```
   query {
       products(search: "testsku" ) {
           items {
               sku
               name
               description {
                   html
               }
               short_description {
                   html
               }
   
               price_range {
                   maximum_price {
                       final_price {
                           value
                           currency
                       }
                       regular_price {
                           value
                           currency
                       }
                   }
               }
           }
       }
   }
   ```

<u>Resultados esperados</u>:

A consulta `products` retorna o nome de produto salvo com suas aspas duplas originais.

<u>Resultados reais</u>:

O nome do produto retornado contém aspas duplas com escape de HTML em vez dos caracteres originais.
