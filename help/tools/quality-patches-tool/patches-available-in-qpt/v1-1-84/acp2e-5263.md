# ACP2E-5263: A exportação de produtos CSV é interrompida antecipadamente e omite produtos

O patch ACP2E-5263 corrige um problema em que uma exportação de produto CSV pode parar antes de incluir todos os produtos, o que produz um arquivo incompleto. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 está instalado. A ID do patch é ACP2E-5263. Observe que esse problema está programado para ser corrigido no Adobe Commerce 2.4.10.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.8-p5

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.5 - 2.4.8-p5

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=pt-BR). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

As exportações de produtos para CSV podem ser interrompidas antes que todos os produtos sejam incluídos, o que produz um arquivo incompleto.

<u>Etapas a serem reproduzidas</u>:

1. Verifique se o catálogo contém vários produtos e uma exibição de armazenamento secundário.
2. Use produtos de teste nos quais um rótulo de imagem está definido para a exibição de armazenamento secundário, mas nenhuma imagem de produto correspondente está disponível na exibição de armazenamento padrão.
3. No Admin, vá para **[!UICONTROL System]** > **[!UICONTROL Data Transfer]** > **[!UICONTROL Export]**.
4. Defina **[!UICONTROL Entity Type]** como **[!UICONTROL Products]** e deixe **[!UICONTROL Export File Format]** definido como **[!UICONTROL CSV]**.
5. Deixe os filtros de exportação em branco e não exclua atributos.
6. Role para baixo e clique em **[!UICONTROL Continue]**.
7. Aguarde a conclusão da exportação assíncrona, baixe e abra o arquivo CSV.

<u>Resultados esperados</u>:

A exportação é concluída e produz um CSV que contém todos os produtos.

<u>Resultados reais</u>:

A exportação é interrompida parcialmente, mas o Administrador indica que o arquivo de exportação está pronto e fornece um CSV que não contém alguns produtos.
