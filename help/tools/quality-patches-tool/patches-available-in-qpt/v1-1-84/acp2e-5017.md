# ACP2E-5017: Falha na consulta de função do cliente do GraphQL para clientes sem uma empresa

O patch ACP2E-5017 corrige o problema em que o campo `role` da consulta `customer` do GraphQL retorna o *erro interno do servidor* para um cliente que não está atribuído a uma empresa. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84 está instalado. A ID do patch é ACP2E-5017. Observe que este problema está programado para ser corrigido no Adobe Commerce B2B 1.5.4.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) B2B 1.5.3

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) B2B 1.5.0 - 1.5.3

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=pt-BR). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

O campo `role` da consulta `customer` do GraphQL retorna *Erro interno de servidor* para um cliente que não está atribuído a uma empresa.

<u>Pré-requisitos</u>:

B2B está instalado.

<u>Etapas a serem reproduzidas</u>:

1. No Admin, vá para **[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL General]** > **[!UICONTROL B2B Features]**, defina **[!UICONTROL Enable Company]** como *[!UICONTROL Yes]* e clique em **[!UICONTROL Save Config]**.
1. Crie uma conta de cliente que não esteja atribuída a uma empresa.
1. Envie a seguinte consulta do GraphQL usando um token de cliente válido:

```
   query {
     customer {
       email
       firstname
       role {
         id
         name
       }
     }
   }
```

<u>Resultados esperados</u>:

A consulta retorna os dados do cliente com o `role` definido como *null*, sem erros.

<u>Resultados reais</u>:

A consulta retorna *Erro interno do servidor*.
