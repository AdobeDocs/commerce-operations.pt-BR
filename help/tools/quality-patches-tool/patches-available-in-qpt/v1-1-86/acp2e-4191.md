# ACP2E-4191: As solicitações da API REST entram em loop infinito quando o cache de tipos e atributos EAV está desabilitado

O patch ACP2E-4191 corrige o problema em que determinadas solicitações da API REST entram em um loop infinito quando o cache de tipos e atributos de EAV está desativado. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 está instalado. A ID do patch é ACP2E-4191. Observe que esse problema foi corrigido no Adobe Commerce 2.4.9.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.7-p9, 2.4.8-p2

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.5 - 2.4.8-p5

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

Certas solicitações de API REST entram em um loop infinito quando o cache de tipos e atributos de EAV é desativado.

<u>Pré-requisitos</u>:

Extensão [!DNL B2B] do Adobe Commerce.

<u>Etapas a serem reproduzidas</u>:

1. Crie uma conta de cliente e faça logon na Loja.
1. Adicione um produto ao carrinho e abra a página de check-out.
1. Nas ferramentas de desenvolvedor do navegador, abra a guia Rede e inspecione as solicitações REST, como `rest/default/V1/carts/mine/estimate-shipping-methods`.
1. Desative o cache de tipos e atributos de EAV:

   ```
   bin/magento cache:disable eav
   ```

1. Atualize a página de check-out e inspecione as mesmas solicitações REST.

<u>Resultados esperados</u>:

1. As solicitações REST de check-out são concluídas sem inserir um loop infinito.

<u>Resultados reais</u>:

1. As solicitações REST falham com o erro HTTP 500 porque o loop infinito atinge o tamanho da pilha de chamadas do PHP ou o limite de memória.
