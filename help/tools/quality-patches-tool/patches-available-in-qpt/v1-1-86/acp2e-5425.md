# ACP2E-5425: Os clientes recebem emails de confirmação de pedido duplicados para o mesmo pedido

O patch ACP2E-5425 corrige o problema em que os clientes recebem emails de confirmação de pedido duplicados para o mesmo pedido. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 está instalado. A ID do patch é ACP2E-5425. Observe que esse problema está programado para ser corrigido no Adobe Commerce 2.4.10.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.7-p10

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.5 - 2.4.7-p10

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

Os clientes recebem emails de confirmação de pedido duplicados para o mesmo pedido.

<u>Etapas a serem reproduzidas</u>:

1. No painel Admin, vá para **[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL Sales]** > **[!UICONTROL Sales Emails]**, expanda **[!UICONTROL General Settings]**, limpe **[!UICONTROL Use system value]**, defina **[!UICONTROL Asynchronous sending]** como *Habilitar* e clique em **[!UICONTROL Save Config]**.
1. Faça um novo pedido na Loja usando um endereço de email válido do cliente e conclua a finalização da compra.
1. Faça com que dois processos executem o trabalho cron `sales_send_order_emails` ao mesmo tempo, para que ambos recebam o email de confirmação do pedido na fila.
1. Verifique a caixa de entrada de emails do cliente para obter mensagens de confirmação do pedido.

<u>Resultados esperados</u>:

É entregue exatamente um email de confirmação do pedido.

<u>Resultados reais</u>:

Dois emails idênticos de confirmação de pedido são entregues ao cliente para o mesmo pedido.

## Etapas adicionais necessárias após a instalação do patch

Após aplicar o patch, execute `setup:upgrade` para atualizar as colunas `email_sent`.
