# ACP2E-4682: Páginas de vitrine que verificam a cotação `isActive` criam registros de cotação vazios

O patch do ACP2E-4682 corrige o problema em que visitar uma página de vitrine que verifica o status da cotação `isActive` cria registros de cotação vazios toda vez que a página é carregada. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82 está instalado. A ID do patch é ACP2E-4682. Observe que esse problema está programado para ser corrigido no Adobe Commerce 2.4.10.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.7-p8

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.5 - 2.4.9

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=pt-BR). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

Visitar uma página de vitrine que verifica o status da cotação `isActive` cria um registro de cotação vazio toda vez que a página é carregada.

<u>Etapas a serem reproduzidas:</u>

1. Personalize uma página de produto da loja e adicione um bloco que verifique o status da cotação `isActive`.
1. Fazer logon em uma conta de cliente.
1. Recarregue a página do produto na loja.
1. Execute a seguinte consulta:

   ```
   SELECT COUNT(*) FROM quote;
   ```

1. Observe que a contagem de cotações aumenta sempre que a página do produto é carregada.

<u>Resultados esperados:</u>

1. Um registro de cotação vazio não é criado quando a página é carregada.

<u>Resultados reais:</u>

1. Um registro de cotação vazio é criado toda vez que uma página contendo a verificação de cotação `isActive` é visitada.
