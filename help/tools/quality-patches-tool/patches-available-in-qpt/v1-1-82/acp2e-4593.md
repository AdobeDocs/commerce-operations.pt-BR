# ACP2E-4593: A página Web Restriction CMS incorreta é disponibilizada no Web site secundário em várias lojas Web sites

O patch ACP2E-4593 corrige o problema em que a página incorreta do CMS de Restrição de Site é servida na vitrine do site secundário em configurações de vários sites porque a chave de cache da página de aterrissagem não tem escopo por site. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82 está instalado. A ID do patch é ACP2E-4593. Observe que esse problema está programado para ser corrigido no Adobe Commerce 2.4.10.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.5-p15

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.5 - 2.4.9

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

A página incorreta do CMS de Restrição de Site é distribuída na loja do site secundário em configurações de vários sites porque a chave de cache da página de aterrissagem não tem escopo por site.

<u>Pré-requisitos</u>:

Inventário instalado.

<u>Etapas a serem reproduzidas</u>:

1. Crie dois sites.
1. Crie duas páginas do CMS, adicione texto diferente a cada página na seção de conteúdo e atribua cada página a um site diferente.
1. Ative as restrições de site e configure uma landing page para o site correspondente.
1. Certifique-se de que o armazenamento em cache esteja ativado.
1. Abra a loja do primeiro site e verifique o conteúdo da landing page exibida.
1. Abra a loja do segundo site e observe que ela ainda exibe o conteúdo da landing page do primeiro site.

<u>Resultados esperados</u>:

Cada site exibe sua respectiva página do CMS corretamente na loja.

<u>Resultados reais</u>:

Ambos os sites exibem a mesma página do CMS, que é a página que foi acessada primeiro.
