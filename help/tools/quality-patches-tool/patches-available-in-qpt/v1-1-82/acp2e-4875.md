# ACP2E-4875: Usuários administradores desconectados ao abrir contas de clientes com catálogos de endereços grandes

O patch do ACP2E-4875 corrige o problema em que a visualização de contas de clientes com catálogos de endereços grandes no Admin faz logout inesperado de usuários administradores. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82 está instalado. A ID do patch é ACP2E-4875. Observe que esse problema está programado para ser corrigido no Adobe Commerce 2.4.10.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.8-p3

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.5 - 2.4.9

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

Os usuários administradores são desconectados inesperadamente ao visualizar contas de clientes com catálogos de endereços grandes no Administrador.

<u>Pré-requisitos</u>:

Uma conta de cliente tem um catálogo de endereços grande que contém aproximadamente 5.000 ou mais endereços salvos.

<u>Etapas a serem reproduzidas</u>:

1. Faça logon no Administrador.
1. Vá para **[!UICONTROL Customers]** > **[!UICONTROL All Customers]**.
1. Na coluna **[!UICONTROL Actions]**, clique em **[!UICONTROL Edit]** para uma conta de cliente que tenha um catálogo de endereços grande.
1. Na página do cliente, abra a guia **[!UICONTROL Addresses]**.

<u>Resultados esperados</u>:

A página do cliente é carregada com sucesso, e todos os endereços salvos do cliente são exibidos.

<u>Resultados reais</u>:

1. O usuário administrador saiu inesperadamente.
1. A sessão excede o tamanho máximo permitido, e uma entrada de log semelhante a *O tamanho da sessão de 1421468 excedeu o tamanho máximo de sessão de 256000* é registrada.
