# ACP2E-4797: O editor WYSIWYG do administrador e o Page Builder bloqueiam caracteres Unicode de 4 bytes quando utf8mb4 for suportado

O patch ACP2E-4797 corrige o problema em que inserir caracteres Unicode de 4 bytes no editor do WYSIWYG ou no conteúdo do Page Builder no Admin é bloqueado incorretamente mesmo quando o banco de dados está configurado para suportar utf8mb4. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82 está instalado. A ID do patch é ACP2E-4797. Observe que esse problema está programado para ser corrigido no Adobe Commerce 2.4.10.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.8-p4

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=pt-BR). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

Não é possível salvar caracteres Unicode de 4 bytes no editor Admin WYSIWYG ou no Page Builder, mesmo quando o banco de dados está configurado para suportar utf8mb4.

<u>Pré-requisitos</u>:

* O WYSIWYG está ativado.
* O Page Builder está ativado.
* O banco de dados está configurado para suportar utf8mb4.

<u>Etapas a serem reproduzidas</u>:

1. Faça logon no Administrador.
1. Vá para **[!UICONTROL Content]** > **[!UICONTROL Elements]** > **[!UICONTROL Blocks]**.
1. Clique em **[!UICONTROL Add New Block]** ou abra um bloco existente no modo de edição.
1. Na seção **[!UICONTROL Content]**, insira estes emojis no editor: 🔵⚪🔴.
1. Para reproduzir o problema no Page Builder, selecione **[!UICONTROL Edit with Page Builder]**. Se necessário, arraste **[!UICONTROL Text]** de **[!UICONTROL Elements]** para o estágio, abra as configurações de tipo de conteúdo de Texto e insira esses emojis no editor: 🔵⚪🔴.
1. Salve as alterações no Page Builder. Se o Page Builder estiver aberto no modo de tela cheia, feche a tela cheia para retornar ao formulário de bloqueio. Em seguida, clique na seta **[!UICONTROL Save]** e escolha **[!UICONTROL Save & Close]**.

<u>Resultados esperados</u>:

O bloco é salvo com sucesso e o conteúdo emoji permanece no conteúdo salvo.

<u>Resultados reais</u>:

Uma mensagem de erro *Remova caracteres inválidos* é exibida.
