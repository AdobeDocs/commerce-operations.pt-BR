# ACP2E-4194: solicitações GraphQL com nomes de filtro desconhecidos causam logs de exceção do PHP

O patch ACP2E-4194 corrige o problema em que solicitações GraphQL com nomes de filtro desconhecidos causam logs de exceção do PHP. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82 está instalado. A ID do patch é ACP2E-4194. Observe que esse problema está programado para ser corrigido no Adobe Commerce 2.4.9.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.7-p10, 2.4.8-p5

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.7-p10, 2.4.8-p5

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

Problema em que as solicitações do GraphQL com nomes de filtro desconhecidos causam logs de exceção do PHP.

<u>Etapas a serem reproduzidas</u>:

Envie uma solicitação do GraphQL que tenha um nome de filtro desconhecido ou incorreto:

```
query Test($filter: FindFilterType){ cmsBlocks(identifiers:["home"]) { items { title } } }
```

<u>Resultados esperados</u>:

Um código de resposta 4XX é retornado se a solicitação não puder ser analisada, se a solicitação não estiver autorizada ou se houver outro problema geral com a solicitação. Se a solicitação puder ser analisada e processada, um código de resposta *200* será retornado.

<u>Resultados reais</u>:

Um erro de servidor interno é retornado na resposta, com o seguinte erro em `exception.log`:

```
report.CRITICAL: LogicException: Config element "FindFilterType" is not declared in GraphQL schema in /var/lib/internal/Magento/Framework/GraphQl/Config.php:57
```
