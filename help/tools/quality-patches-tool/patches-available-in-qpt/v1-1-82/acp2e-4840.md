# ACP2E-4840: a consulta de produtos GraphQL retorna uma quantidade nula para produtos em estoque em estoques de estoque personalizados

O patch ACP2E-4840 corrige o problema em que o campo de quantidade na consulta GraphQL de produtos retorna nulo para produtos que estão em estoque e disponíveis para venda em estoques de estoque personalizados. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82 está instalado. A ID do patch é ACP2E-4840. Observe que esse problema está programado para ser corrigido no Adobe Commerce 2.4.10.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.8-p4

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

O campo de quantidade na consulta de produtos GraphQL retorna nulo para produtos que estão em estoque e disponíveis para venda em estoques de estoque personalizados.

<u>Pré-requisitos</u>:

MSI habilitado.

<u>Etapas a serem reproduzidas</u>:

1. Crie uma nova fonte.
1. Na barra lateral Admin, vá para **[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Stock]**.
1. Clique em **[!UICONTROL Add New Stock]**.
1. Expanda **[!UICONTROL Sales Channels]** e selecione o **[!UICONTROL Websites]** onde o estoque está disponível.
1. Expanda **[!UICONTROL Sources]**, clique em **[!UICONTROL Assign Sources]**, selecione a origem que deseja atribuir e clique em **[!UICONTROL Done]**.
1. Na barra lateral Admin, vá para **[!UICONTROL Catalog]** > **[!UICONTROL Products]** e abra um produto existente no modo de edição.
1. Na seção **[!UICONTROL Sources]**, atribua a origem personalizada, defina **[!UICONTROL Source Item Status]** como **[!UICONTROL In Stock]**, insira um valor diferente de zero para **[!UICONTROL Qty]** e salve o produto.
1. Confirme em **[!UICONTROL Catalog]** > **[!UICONTROL Products]** que o produto mostra um **[!UICONTROL Salable Quantity]** diferente de zero para o site atribuído ao estoque personalizado.
1. Execute a seguinte consulta `products` [!DNL GraphQL] para esse SKU em relação à exibição de loja atribuída ao site que usa o estoque personalizado:

   ```
   query {
     products(filter: { sku: { in: ["product_dynamic_1"] } }) {
       items {
         sku
         name
         stock_status
         quantity
         max_sale_qty
       }
     }
   }
   ```

1. Observe a resposta:

   ```
   {
     "data": {
       "products": {
         "items": [
           {
             "sku": "product_dynamic_1",
             "name": "Simple Product 1",
             "stock_status": "IN_STOCK",
             "quantity": null,
             "max_sale_qty": 10000
           }
         ]
       }
     }
   }
   ```

<u>Resultados esperados</u>:

A resposta do GraphQL retorna um valor de quantidade não nulo para produtos que estão em estoque e podem ser vendidos na loja/site atual.

<u>Resultados reais</u>:

A resposta do GraphQL retorna `quantity = null` enquanto `stock_status` = `IN_STOCK` para produtos que estão em estoque e podem ser vendidos pelo Administrador quando o armazenamento usa um estoque MSI personalizado.
