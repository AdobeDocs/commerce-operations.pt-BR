# AC-11389: Os totais do pedido variam com base no pedido de adição de produtos ao carrinho

O patch AC-11389 corrige o problema em que descontos, impostos e totais de pedidos são calculados incorretamente em alguns cenários de arredondamento. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 está instalado. A ID do patch é AC-11389. Observe que esse problema está programado para ser corrigido no Adobe Commerce 2.4.9.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.8-p3

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.6 - 2.4.8

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

Descontos, impostos e totais de pedidos são calculados incorretamente em alguns cenários de arredondamento.

<u>Pré-requisitos</u>:

Criar produtos de amostra: (Por exemplo: *product1(hat)*, *product2(coat)*)

<u>Etapas a serem reproduzidas</u>:

1. Use uma loja com uma alíquota de imposto de *22%*, um desconto de carrinho de *10%*, um *hat* com um preço especial de *$733.61* e uma *jaqueta* com um preço especial de *$569.67*. 
1. Adicione *três chapéus* e *duas jaquetas* ao carrinho e, em seguida, repita com os produtos adicionados em ordem inversa.
1. Selecione **[!UICONTROL Checkout]**, insira um endereço de entrega no país onde a alíquota de imposto se aplica, aplique o código de desconto e faça o pedido. 

<u>Resultados esperados</u>:

O total do pedido é *$3667.52* para qualquer pedido de produto.

<u>Resultados reais</u>:

O total do pedido é *$3667.51* quando os chapéus são adicionados primeiro e *$3667.50* quando os casacos são adicionados primeiro.
