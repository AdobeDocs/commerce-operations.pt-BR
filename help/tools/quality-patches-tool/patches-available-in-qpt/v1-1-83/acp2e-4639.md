# ACP2E-4639: Tipo de itens da lista de requisições com ortografia incorreta no esquema do Adobe Commerce GraphQL

O patch ACP2E-4639 corrige o problema em que o tipo de itens da lista de requisições é digitado incorretamente no esquema do GraphQL. O novo campo `requisition_list_items` retorna o tipo `RequisitionListItems` digitado corretamente, enquanto o campo `items` mais antigo e o tipo `RequistionListItems` permanecem disponíveis, mas estão obsoletos. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 está instalado. A ID do patch é ACP2E-4639. Observe que esse problema foi corrigido no Adobe Commerce B2B 1.5.3.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) B2B 1.5.2 - p1

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) B2B >= 1.3.4 &lt; 1.5.3

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=pt-BR). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

O tipo de itens da lista de requisições foi digitado incorretamente como `RequistionListItems` no esquema do GraphQL. O campo `items` mais antigo e o tipo `RequistionListItems` permanecem disponíveis, mas estão obsoletos.

<u>Pré-requisitos</u>:

Adobe Commerce com a extensão B2B.

<u>Etapas a serem reproduzidas</u>:

1. Envie a seguinte consulta de introspecção do GraphQL:

   ```
   {
     __type(name: "RequisitionList") {
       fields(includeDeprecated: true) {
         name
         isDeprecated
         type {
           name
         }
       }
     }
   }
   ```

1. Na resposta, verifique o tipo retornado pelo campo `items`.

<u>Resultados esperados</u>:

1. O campo `requisition_list_items` retorna o tipo `RequisitionListItems` digitado corretamente.
1. O campo `items` e o tipo `RequistionListItems` permanecem disponíveis e são marcados como obsoletos.

<u>Resultados reais</u>:

O campo `items` retorna o tipo `RequistionListItems` com erro ortográfico e nenhum campo retorna o tipo `RequisitionListItems` com ortografia correta.
