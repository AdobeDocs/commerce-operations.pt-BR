# AC-12854: A reordenação do administrador usa o número do pedido original com um sufixo `-1`

O patch AC-12854 corrige o problema em que reordenar um pedido no Administrador cria um novo número de pedido com um sufixo `-1` em vez de atribuir o próximo número de pedido sequencial. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 está instalado. A ID do patch é AC-12854. Observe que esse problema está programado para ser corrigido no Adobe Commerce 2.4.9.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.7-p9

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) >=2.4.7 &lt; 2.4.9

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

Reordenar um pedido no Administrador cria um novo número de pedido com um sufixo `-1` em vez de atribuir o próximo número de pedido sequencial.

<u>Etapas a serem reproduzidas</u>:

1. Usar uma ordem de cliente existente com itens reorganizáveis.
1. Na barra lateral Admin, vá para **[!UICONTROL Sales]** > **[!UICONTROL Orders]**.
1. Abra o pedido no modo de **Exibição** e clique em **[!UICONTROL Reorder]** na barra de botões superior.
1. Na página **[!UICONTROL Create New Order]**, preencha os campos obrigatórios e clique em **[!UICONTROL Submit Order]**.

<u>Resultados esperados</u>:

Uma nova ordem **Pendente** é criada com o próximo número de ordem sequencial exclusivo.

<u>Resultados reais</u>:

A nova ordem obtém o número da ordem original com um sufixo `-1` em vez do próximo número da ordem.
