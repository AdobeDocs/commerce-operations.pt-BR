# AC-17975: problemas de compatibilidade do PHP 8.5 afetam comandos CLI, edição de categoria, configuração de design e login do cliente

O patch AC-17975 corrige o problema em que os comandos da CLI, edição de categoria, Configuração de design e logon de cliente do AJAX falham no Adobe Commerce 2.4.9 quando o PHP 8.5 é usado. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 está instalado. A ID do patch é AC-17975. Observe que esse problema está programado para ser corrigido no Adobe Commerce 2.4.9-p1 e 2.4.10.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.9

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.9

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

Comandos CLI, edição de categorias, configuração de design e logon de cliente do AJAX falham quando o Adobe Commerce 2.4.9 é executado no PHP 8.5.

<u>Pré-requisitos</u>:

O PHP 8.5 está instalado.

<u>Etapas a serem reproduzidas</u>:

1. Execute o seguinte comando da CLI:

   ```
   bin/magento --version
   ```

1. Na loja, conclua um check-out e faça logon durante o check-out enquanto o CAPTCHA do cliente está ativado para logon e check-out.
1. No Administrador, abra uma categoria quando um atributo de categoria tiver `frontend_input` definido como `null`.
1. No Admin, vá para **[!UICONTROL Content]** > **[!UICONTROL Design]** > **[!UICONTROL Configuration]** e clique em **[!UICONTROL Edit]** na coluna **[!UICONTROL Action]** para obter uma exibição de loja.


<u>Resultados esperados</u>:

Todas as operações foram concluídas com sucesso.


<u>Resultados reais</u>:

As operações falham com erros, como:

```
Exception #0 (Exception): Deprecated Functionality: Using null as an array offset is deprecated, use an empty string instead
/var/www/html/vendor/magento/framework/App/Config/ScopeCodeResolver.php on line 62
```

```

```

```
There is an error in vendor/magento/framework/Setup/Mvc/MvcApplication.php at line: 170
Undefined constant "Magento\Framework\Setup\Mvc\GLOB_BRACE"
```

```
Deprecated Functionality: Using null as an array offset is deprecated, use an empty string instead in
var/www/html/app/code/Magento/Catalog/Model/Category/DataProvider.php on line 41
```
