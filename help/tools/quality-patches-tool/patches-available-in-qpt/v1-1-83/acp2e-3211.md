# ACP2E-3211: Solicitações paralelas de complemento ao carrinho criam itens separados para o mesmo SKU

O patch do ACP2E-3211 corrige o problema em que adicionar o mesmo produto ao carrinho ao mesmo tempo na Loja cria itens separados no carrinho para o mesmo SKU, em vez de combiná-los em um único item. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 está instalado. A ID do patch é ACP2E-3211. Observe que esse problema foi corrigido no Adobe Commerce 2.4.8.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.5-p7

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.5 - 2.4.7-p10

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

Adicionar o mesmo produto ao carrinho ao mesmo tempo na Loja cria itens separados no carrinho para o mesmo SKU, em vez de combiná-los em um único item.

<u>Etapas a serem reproduzidas</u>:

1. Crie um novo produto.
2. Crie uma nova conta de cliente e faça logon.
3. Vá para a página do produto, abra as **Ferramentas de desenvolvimento** > **Rede** e adicione o produto ao carrinho.
4. Copie a solicitação curl (bash) de adição de produto ao carrinho.
5. Use a consulta curl copiada em duas instâncias do console para acioná-la o mais rápido possível duas vezes.

<u>Resultados esperados</u>:

- O produto é adicionado como um único item de carrinho, com `qty=2`.

<u>Resultados reais</u>:

- O produto é adicionado como dois itens de carrinho separados.
