# ACP2E-4998: SKU ausente impede atualizações de preço de camada em massa para produtos válidos

O patch ACP2E-4998 corrige o problema em que a solicitação da API REST `POST /V1/products/tier-prices` falhava totalmente quando uma SKU na carga não existia, impedindo que SKUs válidas fossem atualizadas. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 está instalado. A ID do patch é ACP2E-4998. Observe que esse problema está programado para ser corrigido no Adobe Commerce 2.4.10.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.7 - p10

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) >= 2.4.7 &lt; 2.4.8

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=pt-BR). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

A solicitação da API REST `POST /V1/products/tier-prices` falhou completamente quando uma SKU na carga não existia, impedindo que SKUs válidas fossem atualizadas.

<u>Etapas a serem reproduzidas</u>:

1. Identifique uma SKU de produto existente, como `product_dynamic_1`, e uma SKU que não existe no catálogo, como `product_dynamic_001`.
1. Envie uma solicitação POST para `/rest/V1/products/tier-prices` contendo ambos os SKUs na mesma carga:

   ```json
   {
     "prices": [
       {
         "sku": "product_dynamic_1",
         "customer_group": "General",
         "quantity": 5,
         "price": 31.99,
         "price_type": "fixed",
         "website_id": 0
       },
       {
         "sku": "product_dynamic_001",
         "customer_group": "General",
         "quantity": 5,
         "price": 54.49,
         "price_type": "fixed",
         "website_id": 0
       }
     ]
   }
   ```

<u>Resultados esperados</u>:

1. O preço da camada é salvo para o SKU existente.
1. A resposta relata a SKU ausente como um erro no nível do item.

<u>Resultados reais</u>:

1. A solicitação falha com o erro *O produto com o SKU &quot;%1&quot; não existe.* para `product_dynamic_001`.
1. Nenhum preço de nível é salvo para o SKU existente.
