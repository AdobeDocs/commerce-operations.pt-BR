# ACP2E-5101: A instalação B2B do Adobe Commerce falha quando os indexadores usam Atualizar por Agendamento

O patch ACP2E-5101 corrige o problema em que a instalação do módulo B2B do Adobe Commerce falhava quando indexadores eram definidos como **[!UICONTROL Update by Schedule]**. Este patch está disponível quando o [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83 está instalado. A ID do patch é ACP2E-5101. Observe que esse problema foi corrigido no Adobe Commerce 2.4.9.

## Produtos e versões afetados

**O patch foi criado para a versão do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) 2.4.6-p15

**Compatível com as versões do Adobe Commerce:**

* Adobe Commerce (todos os métodos de implantação) >=2.4.4 &lt;2.4.7

>[!NOTE]
>
>O patch pode se tornar aplicável a outras versões com as novas versões do [!DNL Quality Patches Tool]. Para verificar se o patch é compatível com a sua versão do Adobe Commerce, atualize o pacote `magento/quality-patches` para a versão mais recente e verifique a compatibilidade na [[!DNL Quality Patches Tool]: página Procurar patches](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=pt-BR). Use a ID do patch como palavra-chave de pesquisa para localizar o patch.

## Problema

A instalação do módulo B2B do Adobe Commerce falha quando os indexadores estão definidos como **[!UICONTROL Update by Schedule]**.


**Nenhum**

<u>Etapas a serem reproduzidas</u>:

1. Na barra lateral Admin, vá para **[!UICONTROL System]** > *[!UICONTROL Tools]* > **[!UICONTROL Index Management]**. Selecione os indexadores, defina **[!UICONTROL Actions]** como **[!UICONTROL Update by Schedule]** e clique em **[!UICONTROL Submit]**.
1. Instale a extensão B2B.
1. Ative todos os módulos B2B.
1. Executar `bin/magento setup:upgrade`.

<u>Resultados esperados</u>:

Os módulos B2B foram instalados com êxito e `bin/magento setup:upgrade` é concluído sem erros quando os indexadores usam **[!UICONTROL Update by Schedule]**.

<u>Resultados reais</u>:

`bin/magento setup:upgrade` falha ao instalar os módulos B2B porque tenta criar um gatilho de banco de dados na tabela `shared_catalog_product_item` antes de a tabela existir.
