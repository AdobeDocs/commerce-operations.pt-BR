# Atualizações da documentação

Esta página lista atualizações da documentação técnica da Adobe Commerce no [Adobe Experience League](https://experienceleague.adobe.com/en/docs/commerce) e no [Adobe Developer](https://developer.adobe.com/commerce/docs/). Use essas listas para encontrar novos tópicos, orientações revisadas e melhorias feitas em resposta aos comentários dos leitores.

As alterações orientadas por feedback abordam sugestões ou problemas levantados pelos leitores, como instruções pouco claras, detalhes ausentes ou informações imprecisas. Por exemplo, o feedback levou a correções sobre o suporte para produtos agrupados na [documentação de recomendações do produto](https://experienceleague.adobe.com/en/docs/commerce/product-recommendations/boundaries-limits).

## Fornecer feedback

Seus comentários ajudam a melhorar a documentação. Você pode contribuir das seguintes maneiras:

* Na Adobe Experience League, use a área de feedback na barra lateral direita ou na parte inferior da página em telas estreitas. Clique no botão para cima ou para baixo para classificar o tópico e revelar o campo de comentário opcional. Para deixar um comentário, insira seu feedback e clique em **[!UICONTROL Submit]**. Consulte o [Guia do colaborador do Adobe Docs na Adobe Experience League](https://experienceleague.adobe.com/en/docs/contributor/contributor-guide/introduction) para obter instruções sobre como relatar problemas e sugerir edições.
* No Adobe Developer, use o repositório GitHub público vinculado a partir do tópico para relatar um problema de documentação ou sugerir uma edição. Consulte [Contribuições à documentação do Adobe Developer](https://developer.adobe.com/commerce/contributor/guides/doc-contributions/) para obter instruções.

Inclua o URL do tópico e descreva o que não está claro, ausente ou incorreto para que a equipe de documentação possa entender sua sugestão.

## Atualizações recentes na documentação

Use a guia **[!UICONTROL All Docs Updates]** para navegar na lista consolidada, ou a guia **[!UICONTROL Feedback Updates]** para ver alterações orientadas por comentários. Cada projeto de documentação define o período coberto por sua lista.
